Two notes for whoever reads this next, neither of them blocking:

- `cmd_input` is cloned and retained for **every** tool call, not only the two it is read for. It is bounded by the transcript's card cap, but for an `Edit` or `Write` call the retained JSON is the whole payload, and narrowing the assignment to `is_ide_command_tool` would be one line. Worth doing if the chat's memory is ever measured.
- `quote_command_arg` quotes on whitespace or a single quote only, so an argument like `a&&b` or `$HOME` renders unquoted. The `IN` line is display, never re-executed, so this is fidelity for a reader copying it out rather than correctness.
